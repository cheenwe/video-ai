# 功能说明

本文描述 **当前已实现** 的平台能力，包括基础平台、海康 NVR 视频接入，以及视频 AI 管理闭环（默认 mock 推理，可替换为 ONNX）。

## 技术架构

| 层 | 技术 |
| --- | --- |
| 后端 | Go + Gin、GORM、纯 Go SQLite（可选 MySQL/PostgreSQL） |
| 前端 | Vue 3 + Pinia + Vite + Tabler UI + TypeScript |
| 部署 | 单进程同时服务 API 与静态前端 |

## 已实现模块

### 认证与会话

- 本地账号登录 / 退出，HttpOnly Cookie 会话
- 验证码（可全局启用或连续失败后强制）
- TOTP 双因素（二维码本地生成，支持强制绑定策略）
- LDAP / OAuth（GitHub、Microsoft、Google 及自定义提供商）
- 登录失败限速、会话撤销（改密/禁用/角色变更后旧会话失效）
- 首次管理员初始化（`BASE_ADMIN_PASSWORD`，默认 `ChangeMe123`）与强制改密

### 用户与组织

- 用户 CRUD、禁用、密码重置、部门归属、Web 登录开关（可创建仅 API 账号）
- 部门树（支持清空上级，校验循环层级）
- 内置角色：`superadmin` / `admin` / `user`
- 自定义 RBAC：权限点、角色授权、用户-角色关联
- 数据范围：`all` / `project` / `dept` / `dept_and_sub` / `self`
- 项目（Project）与成员（owner / admin / member）

### 配置与通用数据

- 系统参数、品牌（站点名、主题色、登录页文案）
- 安全策略（密码规则、登录封禁、验证码、管理员 TOTP）
- 邮件 / LDAP / OAuth / 网关 / 授权 / 水印等配置页
- 字典类型与字典项
- 自定义字段（用户、部门、项目模块，含数据范围校验）

### 运维与集成

- 工作台概览、系统资源监控
- 操作日志、登录日志、审计导出
- API 调用日志（个人访问令牌维度）
- 计划任务（Cron、内置任务、执行记录、手动触发）
- 运维中心：备份创建/下载/恢复准备、NTP 查询
- 站内通知
- Webhook（HMAC 签名、持久投递、重试、去重编号）

### 存储与授权

- 存储源：本地 / S3 / FTP / SFTP / WebDAV，含连接测试与浏览
- 云盘 OAuth 回调
- 商业授权与 nextlicense 兼容（社区版/团队版/旗舰版、离线导入、在线激活、试用、`VA1` 部署指纹）；仓库仅含验签公钥，不含签发私钥

### 视频监控（海康 NVR）

- 登记多台边缘接入节点，对接海康 NVR 4.0（同机 / 分机均可）
- 在线编辑节点设备配置（保存即生效）、通道发现、主/子码流测试
- 实时预览（HLS，经平台代理）、录制启停、本地录像回放与下载、NVR 历史检索与下载
- 节点 Token 加密保存；媒体与 API 统一经平台会话 + RBAC 并审计

详见 [海康 NVR 接入](nvr.md)。

### 视频 AI（M0–M6）

- 平台摄像头 / 分组 / 码流配置，支持绑定 NVR 接入通道或直连 RTSP；拨测探测与 CSV 批量导入（逐行反馈）
- 坑边边界版本（草稿、发布、失效、回滚）与手动折线编辑（AI 候选需真实模型推理，不可用时明确提示）
- 算法资产：基础模型、行为规则（`grab_near_edge` / `grab_cross_boundary`）、业务模板；模型版本发布前经真实加载 + 样例推理自检
- 布控启停 / 暂停 / 自检；期望修订号与运行时已应用版本分离；`AnalysisFPS` 调度与 `Trigger/RecoverHoldSec` 时序滞回
- 真实推理链路：RTSP 拉流（H264/H265）+ ffmpeg 解码（无 CGO）→ JPEG → letterbox/归一化 → 独立 ONNX Runtime worker → 框解码 + NMS；**无 mock/演示适配器**，无帧即 offline
- 告警处置（确认 / 处理 / 关闭，关闭不改现场状态）、事件证据（现场截图 + 事件片段）、报表（含分析质量与离线时长运营指标）、WebSocket 实时推送
- 实时监控 1/4/9/16 路布局切换；NVR 通道 HLS 预览、直连 RTSP MJPEG 预览，Canvas 分析轮廓叠加
- 录像中心：NVR 录像、录像计划（执行依赖 nvr-agent）、事件片段回放
- 扩展接入：GB28181、RTMP/HTTP-FLV/HLS 输入登记、真机探测（SIP OPTIONS / HTTP）与同步为平台摄像头
- 计划任务内置 `evidence_cleanup`；四路压测脚本 `scripts/video-ai-soak.sh`（真实模式 / fail-closed 模式）

详见 [视频 AI](video-ai.md)。

### 开放接口

- 个人访问令牌（`va_…` 前缀），Bearer / `X-API-Key` 调用 REST API
- 健康检查：`/api/health/live`、`/api/health`

## 权限要点

- 管理 API 按动作级权限点校验；超级管理员拥有全部权限。
- 删除类操作及敏感运维（如备份恢复准备）要求超级管理员。
- 用户不能修改自己的管理角色、不能禁用自己；普通管理员不能修改超级管理员。
- 未完成首次改密的账号，服务端限制为仅改密/退出。
- Cookie 写操作校验同源 Origin。

## 响应式与可访问性

管理界面支持桌面侧栏折叠与手机抽屉导航；宽表格在窄屏允许横向滚动。详见归档中的 [移动端与导航验收](archive/移动端与导航验收.md)。

## 未包含 / 限制

- ONNX Runtime 未编入主二进制：推理经独立 worker（`backend/workers/onnx`，CPU provider 已验证协议与管线）；GPU（CUDA）与真实模型效果需在 worker 环境验证
- 模型输出布局按 YOLO detect 解码；其他布局需扩展 `internal/videoai/postprocess.go`
- GB28181 / 推流完整信令与媒体会话（OPTIONS 探测已对接真实协议，未与真机联验）
- 自动坑边真模型候选（演示折线生成器已移除）
- 直连 RTSP 连续录像（录像计划保存后执行依赖 nvr-agent）
- 多租户 SaaS、计费商城、机械停机联锁
- 分布式调度与多实例 SQLite 并发写
