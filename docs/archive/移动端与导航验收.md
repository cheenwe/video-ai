# 移动端与二级导航检查

日期：2026-09-16。基于当前 16 个页面（登录、14 个管理页面、个人中心）与 11 个系统配置页签，使用本机隔离测试数据、浏览器响应式视口检查；不等同于 iOS Safari / Android 真机验收。

## 导航结构

| 一级菜单 | 二级入口 |
| --- | --- |
| 工作空间 | 工作台、项目管理 |
| 组织与权限 | 用户管理、部门管理、角色权限 |
| 平台配置 | 系统配置、字典管理、自定义字段、存储对接、Webhook |
| 运维与审计 | 运维中心、计划任务、系统日志、API 调用日志 |

个人中心通过右上角用户菜单进入，侧栏不再设置“我的账户”分组。

子项继续按 canPage 权限过滤；无可见子项的组不显示。当前页面对应组自动展开，子项高亮；桌面收起后点击组图标展开侧栏。手机使用抽屉，支持关闭按钮、遮罩、Escape，选择页面后关闭；抽屉打开时禁止背景滚动/交互，关闭时隐藏导航不进入键盘焦点。

## 已修复

- 桌面收起状态切到手机时残留 64px 左边距，以及收起侧栏与手机遮罩层级冲突。
- 侧栏菜单较长时不能完整滚动，折叠按钮在侧栏边缘被裁切。
- 通知面板按按钮定位导致窄屏左侧越界；手机固定于屏幕内，并按可视高度限制通知列表。
- 筛选栏、卡片标题操作区、分页按钮的换行和触控尺寸；输入字号调整，降低手机聚焦放大的影响。
- 弹窗宽度、标题换行、页脚按钮和长文本；补充 dialog 可访问语义。
- 授权管理页顶部操作按钮在 320px 下被卡片裁切。
- 用户、角色、项目及项目成员的“更多”下拉菜单被表格滚动容器裁切；改用 fixed 定位，已在用户表格实际点击“详情”验证。
- 导航卸载时清理通知轮询和全局事件监听；同时移除改密弹窗中与当前初始化策略不一致的固定密码提示。
