# 快速开始

## 依赖

- **Node.js** 22+（已在 24 验证）
- **Go** 1.26+（见 `backend/go.mod`）
- 可选：Docker Engine + Compose v2（容器部署）

## 本地开发

### 1. 安装依赖

```sh
make install
# 或分别执行：
# cd frontend && npm ci
# cd backend && go mod download
```

### 2. 启动前端

```sh
cd frontend
npm run dev
```

开发服务器默认 <http://127.0.0.1:5173>，API 代理到后端（见 `BASE_API_TARGET`）。

### 3. 启动后端

另开终端：

```sh
cd backend
# 可选：自定义首次管理员密码；未设置时默认 ChangeMe123
export BASE_ADMIN_PASSWORD='你的密码'
go run ./cmd/baseplatform
```

后端默认监听 <http://127.0.0.1:8181>。

### 4. 登录

| 项目 | 值 |
| --- | --- |
| 地址 | <http://127.0.0.1:5173> |
| 账号 | `admin` |
| 初始密码 | `ChangeMe123`（或你设置的 `BASE_ADMIN_PASSWORD`） |

空数据库首次启动时创建管理员；已有数据库不会覆盖账号。首次登录会强制修改密码。

PowerShell 设置密码示例：

```powershell
$env:BASE_ADMIN_PASSWORD='你的密码'
go run ./cmd/baseplatform
```

## 生产式单进程运行

```sh
make build
BASE_FRONTEND_DIR="$PWD/frontend/dist" ./build/baseplatform
```

Go 进程同时提供 API 与构建后的前端静态资源，生产环境无需 Node.js。

## 常用命令

```sh
make test          # 后端 + 前端测试
make dev-backend   # 仅后端
make dev-frontend  # 仅前端
make docker-up     # Docker Compose 构建并启动
```

## 数据目录

默认数据目录为当前工作目录下的 `./data`，包含：

- `baseplatform.db` — SQLite 数据库（默认驱动）
- `session.key` — 会话签名密钥（未设置 `BASE_SECRET_KEY` 时自动生成）
- `avatars/`、`storage/`、`backups/` 等

生产环境请设置固定的绝对路径 `BASE_DATA_DIR`，并纳入备份策略。详见 [环境变量](环境变量.md) 与 [运维与备份](运维与备份.md)。
